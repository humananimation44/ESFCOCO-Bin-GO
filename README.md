# ESFCOCO-Bin-GO
Team Members: Neel LUNIA, Hector YEUNG, Mitt NGAN.

We are using a pre-existing machine-learning model from MediaPipe to make a seamless integration of motion tracking, we had to use VS code on a computer, as MediaPipe hands require local webcam access.  We also used Perplexity for assistance to troubleshoot and brainstorm. Due to high complexity, we used AI as a tutor and a coding tutor, as it wrote basic models; however, we contributed with heavy engagement, adapting existing code.

MediaPipe Hands : https://mediapipe.readthedocs.io/en/latest/solutions/hands.html
